선형회귀: y = a·x + b

잔차(실제값 − 예측값)의 제곱합이 가장 작아지는 a, b를 찾습니다. 경사하강법은 아무 값에서 출발해 손실의 기울기(미분값)가 내려가는 방향으로 조금씩 이동하기를 반복합니다. 결과를 최소제곱법 공식과 비교해 구현이 맞는지 확인합니다.

학습률이 너무 커서 손실이 발산했습니다. 바닥을 지나쳐 반대편으로 튀기를 반복하며 점점 멀어지는 상태입니다. 학습률을 낮춰보세요.

결과 비교: 경사하강법 vs 최소제곱법 공식

반복 횟수가 충분하면 두 방법의 a, b가 같아집니다. 학습률이 너무 작으면 바닥까지 못 가고, 너무 크면 발산합니다.

잔차 그래프

잔차가 0 주변에 고르게 흩어지지 않고 휘어진 모양을 그리면 직선이 맞지 않는 데이터라는 뜻입니다. 이때 비선형회귀가 필요합니다.

비선형회귀

다항 회귀는 테일러 급수처럼 x², x³ … 항을 더해 곡선으로 맞춥니다(1차면 선형회귀와 같음). 거듭제곱 모델 y = a·xb는 양변에 로그를 취하면 ln y = ln a + b·ln x 라는 직선이 되므로, 선형회귀와 같은 최소제곱법으로 풉니다.

인공신경망: 여러 변수로 예측하기

다항 회귀는 몇 차식을 쓸지 사람이 정해야 하고 입력 변수도 하나뿐이었습니다. 인공신경망은 여러 입력을 받아 가중합 → 활성화 함수를 여러 층 거치면서 곡선의 모양을 데이터에서 스스로 학습합니다. 학습은 과제 1의 경사하강법과 같은 원리로, 역전파로 모든 가중치의 기울기를 구한 뒤 손실이 줄어드는 방향으로 조금씩 이동합니다.

에포크에 따른 손실 (학습 vs 검증)

학습 손실은 계속 줄어도 처음 보는 검증 데이터의 손실이 다시 오르기 시작하면 과적합입니다. 검증 손실이 가장 낮았던 시점의 가중치를 최종 모델로 씁니다.

신경망 구조와 학습된 가중치

원은 뉴런, 선은 가중치입니다. 선이 굵을수록 가중치의 크기가 큽니다.

양(+)의 가중치 음(−)의 가중치

예측값 vs 실제값 (테스트 데이터)

점이 대각선(예측 = 실제)에 가까이 모일수록 잘 맞춘 것입니다.

입력 변수 중요도

테스트 데이터에서 한 변수의 값만 무작위로 섞었을 때 R²가 얼마나 떨어지는지 봅니다. 많이 떨어질수록 신경망이 그 변수에 크게 의존한다는 뜻입니다.

신경망이 스스로 찾은 곡선

입력이 하나일 때는 신경망이 학습한 함수를 곡선으로 그릴 수 있습니다. 차수를 정해주지 않았는데도 2차 다항식과 비슷한 모양을 스스로 찾았는지 비교합니다.
