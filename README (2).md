# 🌊 해양 관측 데이터 회귀분석 프로그램

데이터처리개론 과제 1 — 선형회귀와 비선형회귀 프로그래밍 실습
주제: 해상 풍속과 유의파고의 관계 분석 (기상청 해양기상부이 관측자료)

- 실행 링크: (Streamlit 배포 후 주소 입력)
- 설명서(Notion): (노션 주소 입력)

## 기능
- CSV(UTF-8/CP949) / Excel 파일 불러오기, X/Y축 자동·수동 선택, 결측·오류값 제거
- 선형회귀: 경사하강법 직접 구현 + 최소제곱법 공식과 결과 비교, 손실 감소 그래프, 잔차 그래프
- 비선형회귀: 다항 회귀(1~8차) + 거듭제곱 모델(y = a·x^b, 로그 변환 후 최소제곱),
  차수별 학습/테스트 R² 비교로 과적합 확인
- 인공신경망: 다음 과제에서 추가 예정

## 사용 데이터
기상청 기상자료개방포털(data.kma.go.kr) → 데이터 → 기상관측 → 해양 → 해양기상부이, 시간자료

## 로컬 실행
```
pip install -r requirements.txt
streamlit run app.py
```

## 파일 구조
- `app.py` : 화면(UI)
- `regression.py` : 회귀 알고리즘 (numpy로 직접 구현)
- `data/` : 샘플 데이터
